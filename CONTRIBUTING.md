# Contributing

## Report a problem

1. Search [existing issues](https://gitlab.com/firelink21/gitlabby/-/issues) first.
2. Open a new issue with a template:
   - [Bug](https://gitlab.com/firelink21/gitlabby/-/issues/new?issuable_template=Bug)
   - [Feature](https://gitlab.com/firelink21/gitlabby/-/issues/new?issuable_template=Feature)
   - [Question](https://gitlab.com/firelink21/gitlabby/-/issues/new?issuable_template=Question)
3. Fill in the environment fields (GitLabby, Omarchy, glab, host). Attach screenshots when you can.
4. **Never paste a GitLab token, password, cookie, or `glab auth` / `glab config` output.**

The project is private today, so only members can open issues. Ask the maintainer for Guest access if you need to file one, or wait until the project is public.

## Send a change

Send changes as [merge requests on GitLab](https://gitlab.com/firelink21/gitlabby/-/merge_requests).

The [GitHub repository](https://github.com/odevvy/gitlabby) is a read-only mirror.
GitHub pull requests are not accepted or merged. Please send them on GitLab instead.
