# Contributing

## Report a problem

1. Search [existing issues](https://gitlab.com/o_devvy/gitlabby/-/issues) first.
2. Open a new issue with a template:
   - [Bug](https://gitlab.com/o_devvy/gitlabby/-/issues/new?issuable_template=Bug)
   - [Feature](https://gitlab.com/o_devvy/gitlabby/-/issues/new?issuable_template=Feature)
   - [Question](https://gitlab.com/o_devvy/gitlabby/-/issues/new?issuable_template=Question)
3. Fill in the environment fields (GitLabby, Omarchy, glab, host). Attach screenshots when you can.
4. **Never paste a GitLab token, password, cookie, or `glab auth` / `glab config` output.**

## Send a change

Send changes as [merge requests on GitLab](https://gitlab.com/o_devvy/gitlabby/-/merge_requests).

The [GitHub repository](https://github.com/odevvy/gitlabby) is a read-only mirror.
GitHub pull requests are not accepted or merged. Please send them on GitLab instead.
